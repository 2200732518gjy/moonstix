# Third-party material

MoonStix is an independent MoonBit implementation. It is not a copy of the Python source tree.

## OASIS STIX 2.1

- Specification: https://docs.oasis-open.org/cti/stix/v2.1/os/stix-v2.1-os.html
- Copyright: OASIS Open
- Used as the behavioural reference for object types, common properties, relationship constraints, and the patterning grammar.

## oasis-open/cti-python-stix2

- Source: https://github.com/oasis-open/cti-python-stix2
- License: BSD-3-Clause
- Used as the comparable library for object coverage and validation behaviour.

## oasis-open/cti-pattern-matcher

- Source: https://github.com/oasis-open/cti-pattern-matcher
- License: BSD-3-Clause
- Used as the comparable library for STIX patterning parse coverage.

The BSD-3-Clause license requires copyright and license notice retention. This port does not copy Python modules; it reimplements the object tables and parser in MoonBit.

Redistribution of those upstream projects remains under their own licenses.
